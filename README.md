# rootwriters

`rootwriters` — это загружаемый (out-of-tree) модуль ядра Linux, который реализует разграничение доступа на запись к обычным файлам, владельцем которых является суперпользователь (`UID=0`). 

Список авторизованных пользователей читается из конфигурационного файла `/etc/fsc/rootwriters`.

## Описание работы модуля

Модуль перехватывает операции записи в файлы на уровне ядра (через Ftrace) и применяет следующую логику (только к обычным файлам, принадлежащим `root`):

- Если файл конфигурации `/etc/fsc/rootwriters` **не существует**, дополнительные ограничения не применяются (запись разрешена согласно стандартным правам доступа ОС).
- Если файл `/etc/fsc/rootwriters` **существует, но пуст**, запись в такие файлы запрещена абсолютно всем.
- Если файл содержит **список разрешенных UID**, запись в файлы суперпользователя разрешается только этим пользователям, а остальным блокируется (`Permission denied`).

Изменения в конфигурационном файле отслеживаются динамически и применяются без необходимости перезагрузки модуля ядра.

## Формат конфигурационного файла

Файл `/etc/fsc/rootwriters` поддерживает:
- пустые строки;
- строки комментариев (начинающиеся с `#`);
- внутристрочные комментарии (всё, что идет после `#`);
- дополнительные информационные поля (например, имена пользователей).

Модуль учитывает только первое слово (токен) в каждой строке до пробела или табуляции, которое должно быть числовым идентификатором пользователя (`UID`).

**Пример (`/etc/fsc/rootwriters`):**
```text
# Авторизованные пользователи
0 root
1000 alex_isaev # доступ для разработчика
```

## Требования к системе

- Ubuntu 24.04 (или другой Debian-подобный дистрибутив)
- Наличие прав `sudo`
- Установленные заголовки ядра (`linux-headers`), соответствующие текущей версии ядра
- Утилиты для сборки (`make`, `gcc` / `build-essential`)

## Быстрый старт

Клонируйте проект в вашу виртуальную машину Linux:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd rootwriters
```

Сделайте Bash-скрипты исполняемыми:

```bash
chmod +x scripts/install.sh scripts/test.sh
```

Соберите и установите модуль:

```bash
bash scripts/install.sh
```

Запустите функциональные тесты, чтобы убедиться в корректной работе:

```bash
bash scripts/test.sh
```

## Что делает `install.sh`

Скрипт `scripts/install.sh` автоматизирует рутину:
1. проверяет наличие заголовков ядра (и пытается установить их при отсутствии);
2. собирает модуль (`make`);
3. создает базовый файл `/etc/fsc/rootwriters` (если его нет), добавляя туда `root` и вашего текущего пользователя;
4. выгружает старую версию модуля, если она была загружена;
5. загружает новую версию с помощью `insmod`.

## Что делает `test.sh`

Скрипт `scripts/test.sh` проверяет граничные случаи работы модуля:
1. **Отсутствие конфигурации** -> проверяет, что ограничения сняты.
2. **Пустой файл** -> проверяет, что запись блокируется для всех.
3. **Чужой UID в конфигурации** -> проверяет, что текущему пользователю отказано в записи.
4. **Ваш UID в конфигурации** -> проверяет, что запись проходит успешно.

Во время тестирования создается временный файл, а оригинальный конфигурационный файл бэкапится и восстанавливается по завершении.

## Ручное управление

Собрать проект:
```bash
make
```

Загрузить модуль в ядро:
```bash
sudo insmod rootwriters.ko
```

Проверить статус и логи:
```bash
lsmod | grep rootwriters
sudo dmesg | tail
```

Выгрузить модуль:
```bash
sudo rmmod rootwriters
```

## Примечания

- Проект разработан в исследовательских и образовательных целях.
- Модуль нацелен на перехват вызовов `vfs_write`, что покрывает основные операции записи в обычные файлы.
- Рекомендуется проводить тестирование исключительно на виртуальных машинах.
